# Purple Solitaire

A visually stunning, neon-purple themed Solitaire card game built from the ground up using the **Godot Engine**. 

Featuring a sleek, space-inspired aesthetic with vibrant cosmic backgrounds, custom UI animations, and polished interactions, **Purple Solitaire** reinterprets the classic card game experience within a modern, atmospheric digital environment.

## 🚀 Features
* **Atmospheric Visuals:** High-quality cosmic purple backdrop coupled with customized glowing neon UI buttons.
* **Independent Animation Scripts:** Modular code structure where button glow animations and main menu workflows run on separate, specialized scripts.
* **Built with Godot:** Optimized performance using Godot Engine's native 2D node ecosystem and GDScript.

## Built With
* [Godot Engine](https://godotengine.org) - Versatile and lightweight open-source game engine.
* GDScript - High-performance script optimized for Godot's node hierarchy.
